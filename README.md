# pitcherdashboard

A Pitching Report designed for:

New College Mighty Banyans Baseball 
Sarasota, Florida 
(NAIA Sun Conference)
<br>

# What does this accomplish?
<br>
The report is designed for in-game, live, bullpen, etc. for a pitcher to review how he preformed based on metrics a coaching staff deems 'important' for a pitcher to understand.

This can be tracked and made for everytime a pitcher makes an apperance. In turn, this can show short/long term growth or regression and shape weekly training plans. 

If used CORRECTLY and displays the right information for a pitcher/staff, it can elevate their game and provide context towards their next apperance. 

If used INCORRECTLY, whether the pitcher/staff doesn't use it or displays irrelevant/wrong information, could lead a pitcher to worse results.

Or could not be in either extreme and provide a neutral effect.
